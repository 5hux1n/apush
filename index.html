核心能力

不只是转发，而是智能分发

🔌

多来源接入

一台服务提供多条 Webhook 路径，每个来源独立配置。GET / POST / JSON / 表单 / 纯文本全兼容，无需对齐数据格式。

🧠

智能字段识别

30+ 字段别名自动匹配。无论上游传 title/subject/name、content/body/message/desp，都能正确解析。

🎯

策略引擎

关键词 / 正则 / 时间段 / 来源过滤。支持字段提取和内容清洗，灵活决定哪些消息推送到哪些通道。

📝

消息模板

每个通道独立 {{变量}} 模板。企业微信支持 text/markdown/textcard/news，钉钉支持 markdown/text，自由拼接推送内容。

📊

流转追踪

每条消息从接收到投递全程记录。谁发的、命中哪条策略、推到哪些通道、成功还是失败，一目了然。

🔒

数据自有

部署在你自己的服务器上，数据不过第三方。管理面板密码保护 + 暴力破解防护 + 来源 Token 鉴权。

使用场景

不管是个人自动化还是团队监控，aPush 都能胜任

📱 iPhone 快捷指令 → 多通道通知

通过快捷指令的「获取 URL 内容」动作，GET 请求 /api/webhook/iphone 传入消息。aPush 自动推送到你所有配置的通道，不再只依赖 Bark。

🖥️ 服务器监控告警

Cron 脚本或 Zabbix/Prometheus 触发告警时，curl POST 一条 JSON 到 aPush，自动路由到企业微信 + 钉钉 + 邮件，确保关键告警不遗漏。

📊 业务数据实时推送

订单通知、用户注册、异常日志……后端代码中一行 HTTP 请求，就能让关键事件实时抵达你的手机、电脑、邮箱。

🤖 CI/CD 流水线通知

GitHub Actions / GitLab CI 在构建完成或失败时 Webhook 到 aPush，按分支/状态匹配策略，成功发 TG，失败发钉钉 + 邮件。

🏠 智能家居 & IoT

HomeAssistant、Node-RED 等平台触发事件时，调用 aPush 将通知推送到手机。支持 GET 传参，极低门槛。

💰 薅羊毛 & 抢购通知

爬虫监测到优惠/补货时即时推送。正则关键词匹配，只推你关心的商品，避免信息轰炸。
